# THE PENTAGON

A Connected Digital Ecosystem for Smarter Learning.

**THE PENTAGON** brings students, teachers, resources, and classroom insights together in one connected digital ecosystem, powered by NightBerrieZ.

## Features

- **Interactive 3D Digital Brain**: WebGL/Three.js animated neural network background with cursor tracking, synapses, and traveling light pulses.
- **Pentagon Intro Animation**: Canvas particle convergence with stagger letter reveal and skip option.
- **Role-Based Authentication**: Portals for Students, Faculty, School Administration, and System Administrators with session persistence.
- **Student Dashboard**:
  - Profile customization (avatar, banner, bio, grade, school).
  - Academic performance tracker with subject-wise marks and CGPA calculations.
  - Skills inventory (Academic & Extra-curricular with proficiency levels).
  - Achievements and awards showcase.
  - Learning progress tracker with daily streaks, interactive course completion sliders, goals checklist, and timeline.
  - Community co-learner recommendations matched on interests and skills.
- **My Class**:
  - Class leaderboard ranking with peer averages.
  - Performance analytics (class average comparison vs student).
  - Attendance breakdown and statistics.
  - Upcoming live sessions and class timetable.
- **My Calendar**:
  - Full academic year calendar with month tabs and subject filters.
  - Searchable topics and notes.
  - Handwritten, teacher board, and AI notes indicators.
  - Personal events manager.
  - ICS calendar export and PDF/print support.
- **Create Post**:
  - 15 post types with categories, results (Won, Participated), visibility settings, cover image, and live preview.
- **Teacher Profile**:
  - Pedagogical biography, timeline, and education.
  - Teaching details, subjects, grades, and philosophy.
  - Post composer with reaction tracking and impressions analytics.
  - Portfolio grid (publications, workshops, curriculum, awards).
  - Resource library with download and view metrics.
  - Endorsements and recommendations.

## Tech Stack

- **React 19 & TypeScript**
- **Vite**
- **Three.js** (WebGL 3D brain visualization)
- **Tabler Icons**
- **Custom CSS** with complete design fidelity preserved
